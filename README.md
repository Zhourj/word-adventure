# Coco's Word Adventure 🦊

A fun, single-file HTML word-learning game for 5–6 year olds.

A talking fox (Web Speech API — everything spoken aloud, no reading needed) teaches 153 words in 51 themed sets of 3: animals, food, nature, and everyday things.

Teaching loop per word: **Meet** (see + hear + spelled aloud) → **Find the picture** → **Spell the word** (tap letters, each speaks its phonics sound, hints fade) → **Missing first letter**. Missed words return soon with easier hints (spaced repetition); two clean wins = word learned (golden star + "My Words" shelf). Shape/number/color bonus rounds every 3rd round. No timers, no penalties.

Play it via GitHub Pages (see repo settings) or just open `index.html` in any browser — works offline.
